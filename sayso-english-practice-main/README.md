# Sayso — English Learning

Sayso is a lightweight, responsive English-learning app with a Simplified Chinese interface for practicing English grammar and building everyday vocabulary.

## Features

- Grammar lessons organized into Basic, Elementary, and Intermediate levels
- Lessons for all 12 English tenses, with examples and quick exercises
- Vocabulary browsing by category and subtopic
- Search and part-of-speech filters
- Simplified Chinese explanations and vocabulary meanings
- Original English examples, practice questions, answers, and verb forms
- Responsive layout for phones, tablets, and computers

## Run locally

No installation or build step is required. Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Upload `index.html`, `app.js`, `styles.css`, and this `README.md` to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder, then save.
5. After deployment, open the website link shown in the Pages settings. You can bookmark it or open it on your phone.

## API and data

The grammar and vocabulary lessons work without an API key or server. The app is a static website; its interactive features run in your browser.
